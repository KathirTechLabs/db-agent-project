# Project instructions

This repository uses the Superpowers workflow for agent work.

If you are working in GitHub Copilot CLI, install the plugin with:

```bash
copilot plugin marketplace add obra/superpowers-marketplace
copilot plugin install superpowers@superpowers-marketplace
```

Once installed, follow the `using-superpowers` workflow:

- start with brainstorming before implementation
- write and review a design before coding
- use the Superpowers planning and subagent workflow for execution

Upstream project: https://github.com/obra/superpowers
